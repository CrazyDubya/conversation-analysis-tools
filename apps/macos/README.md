# GPT-Analyze2

A macOS SwiftUI app for analyzing GPT conversation exports. A restart of `GPT-Analyze` with the same Xcode structure.

## What's here

- `GPT_Analyze2/` — the app sources.
- `GPT_Analyze2.xcodeproj` — open and build.
- `EFFICIENCY_REPORT.md`, `SWARM_ANALYSIS_REPORT.md` — generated assessments. Not documentation of the code.

## Status

Seven commits, December 2025 — one month after `GPT-Analyze`, which has six. Of the two this is the later.
